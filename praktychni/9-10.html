Практична робота № 2

Створення текстового документа, що містить об’єкти різних типів

Тема: Текст · Microsoft Word

!

Увага! Під час роботи з комп’ютером дотримуйтеся вимог безпеки життєдіяльності та санітарно-гігієнічних норм.

Завантажте файл Практична_2 варіант 1 і відкрийте його в Microsoft Word. Якщо зверху жовта смуга Захищений перегляд, натисніть Дозволити редагування. Увімкніть приховані символи: вкладка Основне, кнопка ¶ (Ctrl+Shift+8).

Номери списку ставить Word. Не набирайте «1.» чи «1)» вручну, а рівень змінюйте клавішами Tab і Shift+Tab.

Завдання 1

Оформіть інструкцію як багаторівневий список: абзаци синього кольору — І рівень, фіолетового — ІІ рівень, зеленого — ІІІ рівень. Нумерація рівнів має бути такою: 1. / 1) / 1. Потім розмістіть останній абзац у два стовпці й додайте колонтитули.

  1. Виділіть увесь текст під червоним заголовком. Вкладка Основне, група Абзац, Багаторівневий список → Визначити новий багаторівневий список… Рівень 1: формат номера «1.»; рівень 2: стиль 1, 2, 3, формат «1)»; рівень 3: стиль 1, 2, 3, формат «1.». Натисніть OK.
  2. Клацніть у фіолетовому абзаці, Основне → Виділити → виділення тексту з подібним форматуванням, натисніть Tab. Так само виділіть зелені абзаци й натисніть Tab двічі.
  3. Виділіть останній абзац: Макет → Параметри сторінки → Стовпці → Більше стовпців… Кількість — 2, прапорець Стовпці однакової ширини, ширина — 7 см, OK.
  4. Вставлення → Верхній колонтитул → Пустий. Введіть назву документа, потім на вкладці Колонтитули кнопка Дата й час → сьогоднішня дата → OK.
  5. Перейти до нижнього колонтитула, введіть своє прізвище, Закрити колонтитули. Збережіть файл з іменем Прізвище_ПР2.1.

Перевірте себе

клацніть по номеру зеленого абзацу — сірим підсвітяться всі номери ІІІ рівня. Перший синій абзац має номер 1., фіолетові під ним — 1), 2), 3), а дата й прізвище видно на кожній сторінці.

Завдання 2

Створіть новий документ (Файл → Створити → Новий документ) і введіть три формули за зразком.

  1. Формула а): Вставлення → Символи → Рівняння. Букву ρ візьміть у групі Символи вкладки Рівняння (набір Грецькі літери) або введіть \rho і пропуск. Індекс 0 — Структури → Індекс, дріб — Структури → Дріб.
  2. Формула б) — без конструктора: наберіть текст, виділіть цифру, вкладка Основне → кнопка Підрядковий знак (Ctrl+=). Стрілку вставте через Вставлення → Символ → Інші символи…, набір Стрілки.
  3. Формула в): у конструкторі три дроби (Структури → Дріб), степені — Структури → Індекс з верхнім індексом. Після кожного дробу переходьте вправо клавішею зі стрілкою.
  4. Збережіть файл з іменем Прізвище_ПР2.2.

Так має виглядати результат:

а) Густина твердого тіла ρ = ρ₀ · P / (P − P₁) — записати дробом: зверху P, знизу P − P₁
б) KMnO₄ → K₂MnO₄ + MnO₂ + O₂
в) (3x² + 7) / 4 − (x³ − 3) / 2 = (5x + 2) / 8 — кожну частину записати дробом

Перевірте себе

клацніть по формулі а) або в): навколо неї з’являється рамка й вкладка Рівняння. У формулі б) цифри дрібні й опущені вниз, а не набрані звичайним шрифтом.

Завдання 3 (додаткове)

Відкрийте файл Практична_2 варіант 2 «Кібербезпека у сучасному світі» і оформіть його так само на три рівні, але з власним виглядом списку.

  1. Зелені абзаци — І рівень, сині — ІІ, коричневі — ІІІ. Для ІІІ рівня у вікні Визначити новий багаторівневий список… виберіть Новий маркер… і знайдіть символ, наприклад ✓.
  2. Поставте курсор перед абзацом «Технічні засоби захисту»: Макет → Розриви → Розриви розділів → Наступна сторінка.
  3. У нижній колонтитул вставте номер сторінки: Вставлення → Номер сторінки → Внизу сторінки, а у верхній — знак © і своє прізвище (Вставлення → Символ).
  4. Збережіть файл з іменем Прізвище_ПР2.3.

Перевірте себе

документ має дві сторінки, і розділ «Технічні засоби захисту» починається з нової сторінки.

Збережіть усі файли (Ctrl+S) і надішліть учителю Прізвище_ПР2.1 та Прізвище_ПР2.2 (і Прізвище_ПР2.3, якщо виконали додаткове).
