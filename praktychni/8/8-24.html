Завдання 1 · рівень 1 ⭐ «Квадратне рівняння» (обов’язкове)

Проєкт знаходить корені рівняння ax² + bx + c = 0. Кількість коренів залежить від дискримінанта d = b · b − 4 · a · c: d > 0 — два корені, d = 0 — один, d < 0 — коренів немає. У заготовці є поля для a і b та гілка для двох коренів.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-24. Завдання 1: квадратне рівняння
from tkinter import *
from tkinter.messagebox import *
from math import *
def click():
    a = float(enA.get())
    b = float(enB.get())
    c = float(enC.get())
    d = b * b - 4 * a * c
    if d > 0:
        x1 = (-b + sqrt(d)) / (2 * a)
        x2 = (-b - sqrt(d)) / (2 * a)
        s = 'x1 = ' + str(round(x1, 2)) + ', x2 = ' + str(round(x2, 2))
        showinfo('Два корені', s)
root = Tk()
root.title('Квадратне рівняння')
root.geometry('300x300')
labA = Label(text='a')
labA.pack(pady=5)
enA = Entry(width=8)
enA.pack()
labB = Label(text='b')
labB.pack(pady=5)
enB = Entry(width=8)
enB.pack()
btn = Button(text='Знайти корені', command=click)
btn.pack(pady=10)
root.mainloop()
  1. Інтерфейс за зразком полів a і b: перед рядком btn = Button(…) додайте напис і поле для c — labC = Label(text='c'), labC.pack(pady=5), enC = Entry(width=8), enC.pack().
  2. Запустіть (F5), уведіть 1, -5, 6 і клацніть Знайти корені. Порахуйте самі: (−5) · (−5) − 4 · 1 · 6 = 1 > 0 — два корені. Збігається?
  3. Перевірте 1, -4, 4. Що сталося? Тепер під гілкою if, на одному рівні з if, допишіть elif d == 0:, а нижче з відступом — x = -b / (2 * a) і showinfo('Один корінь', 'x = ' + str(round(x, 2))).
  4. Допишіть останню гілку: else: і з відступом showinfo('Коренів немає', 'Рівняння коренів не має').
  5. Доберіть набори a, b, c, щоб рівняння мало два корені, один корінь і не мало коренів (підказка: 1, −4, 4 і 1, 1, 1). Під першим рядком допишіть коментар # Тестували … зі своїми наборами. Збережіть: ⋮ → Файли → Зберегти, ім’я практична24_1.

Встигли? Уведіть 0, 2, 1 і подивіться на повідомлення внизу. Якщо a = 0, рівняння вже не квадратне. Додайте першою гілку if a == 0: з відступом showinfo('Помилка', 'a не може дорівнювати 0'), а if d > 0: замініть на elif d > 0:.

Перевірте себе

Без поля c — помилка NameError: name 'enC' is not defined. 1, −5, 6 — «Два корені», x1 = 3.0, x2 = 2.0; 1, −4, 4 — «Один корінь», x = 2.0; 1, 1, 1 — «Коренів немає». Ваші набори можуть бути іншими: два корені — коли d > 0 (наприклад, 2, 3, −2 — 0.5 і −2.0), один — коли d = 0, жодного — коли d < 0. Розгалуження з трьома гілками — багатоальтернативне. «Встигли?»: без перевірки 0, 2, 1 дає ZeroDivisionError (ділення на 2 · a = 0), з гілкою — повідомлення «Помилка».

Завдання 2 · рівень 2 ⭐⭐ «Чи буде трикутник?»

Вправа 13 до § 4.6: з трьох відрізків можна скласти трикутник, якщо кожна сума двох довжин більша за третю. Проєкт готовий, але в умові перевіряється лише одна сума. Знайдіть помилку тестами й виправте її.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-24. Завдання 2: чи буде трикутник? (вправа 4.6.13)
from tkinter import *
def click():

  2. Тепер 10, 2, 2. Чи можна скласти трикутник з відрізків 10, 2 і 2? Що показав проєкт? Подивіться на умову в if: яку суму вона не перевіряє?
  3. Допишіть в умову ще дві перевірки через and: if a + b > c and a + c > b and b + c > a:. Перевірте 10, 2, 2 знову.
  4. Перевірте межу 1, 2, 3 (1 + 2 дорівнює 3) і 5, 5, 5. Під першим рядком допишіть коментар # Тестували … — які набори й чому. Збережіть з іменем практична24_2.

Встигли? Коли трикутник буде, перевірте, чи він рівнобедрений: у гілці if замість одного рядка напишіть вкладене розгалуження if a == b or b == c or a == c: — напис Рівнобедрений, else: — напис Трикутник буде. Протестуйте 5, 5, 8 і 3, 4, 5.

Перевірте себе

З однією сумою 10, 2, 2 — «Трикутник буде», а це неправильно: 2 + 2 менше за 10. З трьома умовами через and: 3, 4, 5 і 5, 5, 5 — Трикутник буде; 2, 2, 10, 10, 2, 2 і 1, 2, 3 — Трикутника не буде (1 + 2 = 3, а не більше — відрізки лягають в одну лінію). and дає True, лише коли всі умови True. «Встигли?»: 5, 5, 8 і 5, 5, 5 — Рівнобедрений, 3, 4, 5 — Трикутник буде.

Завдання 3 · рівень 3 ⭐⭐⭐ «Скільки це бітів?»

Повторюємо кодування: 1 Б = 8 бітів, 1 кБ = 1024 Б, 1 МБ = 1024 кБ. Проєкт отримує число й одиницю (Б, кБ або МБ) і показує, скільки це бітів. Поки що він знає лише байти.

  2. Після гілки для Б допишіть elif u == 'кБ': і з відступом bits = n * 8 * 1024. Перевірте 1 кБ і 0.5 кБ — спершу порахуйте самі.
  3. Так само допишіть гілку для МБ: bits = n * 8 * 1024 * 1024. Перевірте 2 МБ.
  4. Уведіть 1 і кб (мала «б»). Що показав проєкт і чому? Збережіть з іменем практична24_3.

Встигли? Додайте гілку для ГБ (ще раз помножити на 1024) і змініть текст напису lb2 на «Одиниця: Б, кБ, МБ або ГБ». Скільки бітів в 1 ГБ?

Перевірте себе

Заготовка: 1 Б — 8.0, 1 кБ — «Невідома одиниця» (такої гілки ще немає). Після змін: 1 кБ — 8192.0, 0.5 кБ — 4096.0, 2 МБ — 16777216.0. «кб» — Невідома одиниця: Python порівнює рядки точно, і мала «б» — інша літера. «Встигли?»: 1 ГБ — 8589934592.0 бітів.
