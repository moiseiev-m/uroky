Завдання 2 · рівень 2 ⭐⭐ «Знайди помилки»

Вправа 4.6.2 з е-додатка: проєкт обчислює значення функції y = (x² − 4) / (x² − 25). Коли дільник дорівнює 0, у полі має з’явитися «Вираз значення не має: ділення на 0». Але проєкт містить дві помилки. Протестуйте його й виправте.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-23. Завдання 2: знайди помилки (вправа 4.6.2)
# y = (x² - 4) / (x² - 25)
from tkinter import *
def click():
    entry2.delete(0, END)
    x = float(entry1.get())
    if x == 5:
        y = 'Вираз значення не має: ділення на 0'
    else:
        y = x*x - 4 / x*x - 25
    entry2.insert(0, str(y))
root = Tk()
root.title('Вправа 4.6.2')
root.geometry('300x250')
label1 = Label(text='Значення x')
label1.pack(pady=10)
entry1 = Entry()
entry1.pack()
label2 = Label(text='Значення y')
label2.pack(pady=10)
entry2 = Entry(width=35)
entry2.pack()
button = Button(text='Обчислити значення функції', command=click)
button.pack(pady=20)
root.mainloop()
  1. Порахуйте самі, що має вийти для x = 0: (0 − 4) / (0 − 25). Запустіть проєкт, уведіть 0 і клацніть Обчислити значення функції. Збігається? Подивіться й на повідомлення внизу.
  2. Знайдіть помилку у формулі й виправте її (підказка: що Python рахує першим — ділення чи віднімання?). Запустіть і знову перевірте 0.
  3. Перевірте x = 5: що має вийти? Потім x = -5: (−5) · (−5) = 25 — дільник теж 0. Чи правильна відповідь? Виправте умову в if так, щоб вона спрацьовувала і для 5, і для −5 (підказка: or). Перевірте обидва числа ще раз.
  4. Перевірте ще два числа — 3 і 10: порахуйте самі й порівняйте з проєктом.
  5. Під першим рядком допишіть коментар: # Тестували 0, 5, -5, бо … — поясніть своїми словами, чому саме ці числа. Збережіть з іменем практична23_2.

Встигли? Замініть умову з or однією перевіркою дільника: if x*x - 25 == 0:. Перевірте 5, −5 і 0 ще раз.

Перевірте себе

Помилка 1 — без дужок x*x - 4 / x*x - 25 Python рахує як x · x − (4 / x) · x − 25, і для 0 — ZeroDivisionError. Правильно: y = (x*x - 4) / (x*x - 25), для 0 — 0.16. Помилка 2 — умова перевіряє лише 5, а дільник дорівнює 0 і для −5. Правильно: if x == 5 or x == -5: (або if x*x - 25 == 0:). Тоді 5 і −5 — «Вираз значення не має: ділення на 0», 3 — −0.3125, 10 — 1.28. Тестували 0, 5, −5, бо 5 і −5 — гілка if (дільник 0), 0 — гілка else. Якщо −5 перевірили до виправлення дужок, вийшло −4.0 — теж неправильно.

Проєкт визначає, з одного слова чи з кількох складається введений текст, і повідомляє про це у вікні повідомлень. Між словами стоїть пробіл, тож досить перевірити, чи є пробіл у тексті. Вікно з полем і кнопкою вже створено.

Завдання 2 · рівень 2 ⭐⭐ «Знайди помилки»

Вправа 4.6.2 з е-додатка: проєкт обчислює y = (x² − 4) / (x² − 25). Коли дільник дорівнює 0, у полі має з’явитися «Вираз значення не має: ділення на 0». У проєкті дві помилки — знайдіть їх тестами.
