Практичне завдання

Логічні величини. Логічні вирази

Тема: Програмування

Немає комп’ютера — виберіть «З телефона»: завдання на ту саму тему, їх можна виконати на телефоні.

!

Увага! Під час роботи з комп’ютером дотримуйтеся вимог безпеки життєдіяльності та санітарно-гігієнічних норм.

Працюємо в ЄPython. У кожному завданні є кнопка ▶ Відкрити заготовку в ЄPython — код одразу з’явиться в редакторі.

Обов’язкове — завдання ⭐. Зробили й перевірили себе — переходьте до ⭐⭐, далі ⭐⭐⭐.

True і False пишуть з великої літери. Знаки порівняння: == (дорівнює), != (не дорівнює), >= і <= — знак рівності завжди другий. Один знак = — присвоювання, два == — перевірка «чи рівні?». Логічне значення в напис чи поле — через str(t).

Завдання 1 · рівень 1 ⭐ «Правда чи ні?» (обов’язкове)

Кожен рядок заготовки — висловлювання з математики. Python обчислює, істинне воно (True) чи хибне (False). Спершу передбачте відповідь самі, потім перевірте.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-21. Завдання 1: правда чи ні?
# Спершу передбачте: True чи False? Потім запустіть (F5).
print(4 < 12)
print(2 * 5 - 4 == 6)
print(2 * 7 + 3 == 12)
print(3 > 5)
print(21 <= 21)
print(17 != 17)
  1. Не запускаючи програми, вирішіть для кожного рядка: True чи False? Допишіть відповідь у кінці рядка коментарем, наприклад: print(4 < 12) # True.
  2. Запустіть (F5) і порівняйте зі своїми відповідями. Де не вгадали — порахуйте ще раз, що ліворуч і що праворуч від знака.
  3. Допишіть змінні логічного типу: x = (32 < 13), y = (2 + 12/3 == 6) і print(x, y). Спершу передбачте, що виведе програма, потім запустіть.
  4. Допишіть y = x, print(y) і print(type(x)). Що тепер у змінній y? Якого типу змінна x?
  5. Збережіть: ⋮ → Файли → Зберегти, ім’я практична21_1.

Встигли? Допишіть z = true з малої літери і print(z). Яку помилку покаже ЄPython? Виправте її.

Перевірте себе

Шість рядків: True, True, False (14 + 3 = 17), False, True (21 дорівнює 21), False. Потім False True: 32 < 13 — хибне, а 12/3 = 4.0 і 2 + 4.0 = 6.0 — дорівнює 6. Після y = x у y — False, значення змінної x. Останній рядок — class 'bool': x має логічний тип. z = true — NameError: name 'true' is not defined: правильно True.

Завдання 2 · рівень 2 ⭐⭐ «Калькулятор порівнює»

Наш калькулятор у вікні сьогодні не рахує, а порівнює: користувач уводить два числа, клацає Порівняти — і напис показує True або False. Вікно вже створено, бракує обробника.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-21. Завдання 2: калькулятор порівнює
from tkinter import *
def click():
    pass
root = Tk()
root.title('Порівняння')
root.geometry('300x250')
lb1 = Label(text='Перше число')
lb1.pack(pady=5)
ent1 = Entry()
ent1.pack()
lb2 = Label(text='Друге число')
lb2.pack(pady=5)
ent2 = Entry()
ent2.pack()
lb3 = Label(text='Перше більше за друге?')
lb3.pack(pady=5)
lb = Label(fg='blue')
lb.pack()
bt = Button(text='Порівняти', command=click)
bt.pack(pady=5)
root.mainloop()
  1. Обробник: замість pass наберіть з відступом x = float(ent1.get()), y = float(ent2.get()), t = x > y і lb['text'] = str(t).
  2. Запустіть і перевірте пари чисел 12 і 5, 5 і 12, 3 і 3. Перед кожним клацанням передбачте відповідь.
  3. Для 3 і 3 вийшло False: рівні числа не більші. Замініть у рядку з t знак > на >=, а текст напису lb3 — на Перше не менше за друге?. Перевірте 3 і 3, потім 2.5 і 10.
  4. Приберіть str: lb['text'] = t. Запустіть і клацніть — що тепер показує напис? Поверніть str(t).
  5. Збережіть з іменем практична21_2.

Встигли? Приберіть float у двох рядках: x = ent1.get() і y = ent2.get(). Порівняйте 12 і 5 — чому вийшло False? Поверніть float.

Перевірте себе

З >: 12 і 5 — True, 5 і 12 — False, 3 і 3 — False. З >=: 3 і 3 — True, 2.5 і 10 — False. Без str напис показує 1 замість True і 0 замість False. Без float порівнюються тексти, по одному символу зліва: '1' стоїть раніше за '5', тому '12' «менше» за '5' — False.

Завдання 3 · рівень 3 ⭐⭐⭐ «Чи вистачить грошей?»

Марійка хоче купити кілька однакових шоколадок. Проєкт перевіряє, чи вистачить їй грошей: користувач уводить, скільки грошей дала мама, ціну однієї шоколадки й кількість, а в полі з’являється True або False. У заготовці є лише перше поле й кнопка.

▶ Відкрити заготовку в ЄPython
Показати код заготовки

# Марійка хоче купити кілька однакових шоколадок.
# Вхідні дані: ...
# Результат: ...
# Формула: ...
from tkinter import *
def click():
    pass
root = Tk()
root.title('Чи вистачить грошей?')
root.geometry('300x300')
lb1 = Label(text='Мама дала, грн:')
lb1.pack()
ent1 = Entry()
ent1.pack()
bt = Button(text='Перевірити', command=click)
bt.pack(pady=10)
root.mainloop()
  1. Модель — у коментарях: замість ... наберіть: вхідні дані — s, p, k (гроші від мами, ціна однієї шоколадки, кількість шоколадок); результат — t (True — вистачить, False — ні); формула — t = s >= p * k.
  2. Перед рядком bt = Button(…) додайте за зразком напис lb2 з текстом Ціна шоколадки, грн: і поле ent2, напис lb3 з текстом Скільки шоколадок: і поле ent3.
  3. Після bt.pack(pady=10) додайте напис lb4 = Label(text='Вистачить грошей?') з lb4.pack() і поле для відповіді ent4 = Entry(fg='blue') з ent4.pack().
  4. Обробник: замість pass — s = float(ent1.get()), p = float(ent2.get()), k = int(ent3.get()) (кількість — ціле число), t = s >= p * k, потім ent4.delete(0, END) і ent4.insert(0, str(t)).
  5. Перевірте: 100 грн, ціна 35, 2 шоколадки; потім 3 шоколадки; потім 105 грн і 3 шоколадки. Спершу порахуйте самі. Збережіть з іменем практична21_3.

Встигли? Замініть >= на > і перевірте 105, 35, 3. Чому тепер False? Який знак правильний, якщо грошей рівно на покупку?

Перевірте себе

2 шоколадки коштують 70 грн, 100 не менше за 70 — True. 3 шоколадки — 105 грн, це більше за 100 — False. 105 грн на 3 шоколадки — True: грошей рівно, а >= означає «більше або дорівнює». Зі знаком > вийшло б False — Марійка не купила б шоколадки, хоча грошей вистачає.

Перевірте, що в папці Завантаження є практична21_1.py (і практична21_2.py, практична21_3.py, якщо робили). Закрийте вкладку браузера й повідомте вчителя про завершення роботи.

Завдання 2 · рівень 2 ⭐⭐ «Калькулятор порівнює»

Калькулятор у вікні порівнює два числа: торкніться Порівняти — і напис покаже True або False. Програму вже набрано.

# Калькулятор порівнює

def click():

    t = x > y
    lb['text'] = str(t)

ent1.pack()

ent2 = Entry()
ent2.pack()

lb3.pack(pady=5)
lb = Label(fg='blue')
lb.pack()
bt = Button(text='Порівняти', command=click)
bt.pack(pady=10)
root.mainloop()
  1. Відкрийте заготовку й запустіть. Уведіть 12 і 5, торкніться Порівняти. Потім 3 і 3. Перед кожним дотиком передбачте відповідь.

  3. У рядку lb['text'] = str(t) приберіть str( і закриваючу дужку ) — має бути lb['text'] = t. Що тепер показує напис? Поверніть str(t).

Перевірте себе

З >: 12 і 5 — True, 3 і 3 — False. З >= і написом Перше не менше за друге?: 3 і 3 — True. Без str напис показує 1 замість True і 0 замість False.
