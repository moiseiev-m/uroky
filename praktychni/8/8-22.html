Логічні операції. Логічні вирази в розгалуженнях

Тема: Програмування

Немає комп’ютера — виберіть «З телефона»: завдання на ту саму тему, їх можна виконати на телефоні.

!

Увага! Під час роботи з комп’ютером дотримуйтеся вимог безпеки життєдіяльності та санітарно-гігієнічних норм.

Працюємо в ЄPython. У кожному завданні є кнопка ▶ Відкрити заготовку в ЄPython — код одразу з’явиться в редакторі.

Обов’язкове — завдання ⭐. Зробили й перевірили себе — переходьте до ⭐⭐, далі ⭐⭐⭐.

Логічні операції пишуть малими англійськими словами: not (не), and (і), or (або). Порядок: спершу порівняння, потім not, and, or; дужки — першими. Після умови в if, elif і після else — двокрапка, команди гілки — з відступом. Імена змінних — лише англійськими літерами: українська у й англійська y для Python різні змінні.

Завдання 1 · рівень 1 ⭐ «Обчисли й перевір» (обов’язкове)

Python обчислює логічний вираз з трьох порівнянь і двох операцій. Спершу передбачте відповідь самі, потім перевірте. Наприкінці складете таблицю істинності для and, or і not.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-22. Завдання 1: обчисли й перевір
# Спершу передбачте: True чи False? Потім запустіть (F5).
x = 3
y = 5
z = -2
t = x > 0 and y > 0 or z < 0
print(t)
  1. Не запускаючи, порахуйте: спершу три порівняння, потім and, потім or. Запустіть (F5) і порівняйте зі своєю відповіддю.
  2. Змініть числа на другий набір: x = 4, y = -6, z = -5. Передбачте й запустіть. Потім так само третій набір — 9, -5, 0 і четвертий — -5, -7, 2.
  3. Допишіть у кінці три рядки: a = True, b = False і print(a, b, a and b, a or b, not a). Запустіть: останній рядок результату — це рядок таблиці істинності.
  4. Змініть значення a і b ще тричі так, щоб отримати всі чотири рядки таблиці: True True, True False, False True, False False.
  5. Збережіть: ⋮ → Файли → Зберегти, ім’я практична22_1.

Встигли? Допишіть print(not 5 > 3, True or False and False, (True or False) and False). Спершу передбачте три значення, потім запустіть.

Перевірте себе

Чотири набори: True (3 і 5 додатні), True (z = −5 від’ємне, а or досить однієї умови), False, False. Таблиця: True True — True True True True False; True False — True False False True False; False True — False True False True True; False False — False False False False True. «Встигли?» — False True False: not 5 > 3 — це not True; без дужок спершу and; з дужками спершу or.

Завдання 2 · рівень 2 ⭐⭐ «Вправа 4.5»

Проєкт з е-додатка: у вікні три поля для x, y, z, кнопка Обчислити й поле Результат — значення логічного виразу t = x > 0 and (y > 0 or z < 0). Вікно вже створено, бракує обробника.

Показати код заготовки

  2. Допишіть у обробник виведення в поле: ent4.delete(0, END) і ent4.insert(0, str(t)).
  3. Запустіть і перевірте чотири набори: 5, 8, -2; 5, -8, 3; -5, 8, -4; -5, -8, 5. Перед кожним клацанням на Обчислити передбачте відповідь.

Перевірте себе

Набори: True (5 > 0 і 8 > 0), False (−8 > 0 і 3 < 0 — обидві умови в дужках хибні), False і False (x від’ємне — and дає False). Без дужок набір −5, 8, −4 дає True: спершу виконується and (False), а потім or з z < 0 (True). Якщо після клацання поле Результат порожнє, а внизу помилка NameError — якусь змінну набрано українською літерою.

Завдання 3 · рівень 3 ⭐⭐⭐ «Чи можна Михайлові грати?»

Михайлові дозволяють грати на комп’ютері, якщо він виконав домашнє завдання або навів лад у кімнаті і його старша сестра завершила роботу за комп’ютером. Проєкт «Розумного» будинку: у три поля вводять так або ні, а напис відповідає, чи можна грати. Вікно з полями й кнопкою вже є.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практичне завдання 8-22. Завдання 3: чи можна Михайлові грати?
# d — домашнє виконано, l — лад наведено, s — сестра завершила роботу
from tkinter import *
def click():
    pass
root = Tk()
root.title('Розумний будинок')
root.geometry('300x300')
lb1 = Label(text='Домашнє виконано? (так/ні)')
lb1.pack(pady=5)
ent1 = Entry()
ent1.pack()
lb2 = Label(text='Лад у кімнаті? (так/ні)')
lb2.pack(pady=5)
ent2 = Entry()
ent2.pack()
lb3 = Label(text='Сестра завершила? (так/ні)')
lb3.pack(pady=5)
ent3 = Entry()
ent3.pack()
bt = Button(text='Перевірити', command=click)
bt.pack(pady=10)
lb = Label(font='Arial 14', fg='blue')
lb.pack()
root.mainloop()
  1. Обробник: замість pass наберіть з відступом d = ent1.get() == 'так', l = ent2.get() == 'так' і s = ent3.get() == 'так'. Кожна змінна отримає True або False.
  2. Нижче в обробнику — розгалуження: if (d or l) and s:, з відступом lb['text'] = 'Можна грати!', потім else: і з відступом lb['text'] = 'Ще не можна'.
  3. Запустіть і перевірте чотири випадки (поля по черзі): так, ні, так; ні, так, так; так, так, ні; ні, ні, так. Спершу вирішіть самі.
  4. Приберіть дужки: if d or l and s:. Перевірте так, ні, ні — чому тепер відповідь неправильна? Поверніть дужки.
  5. Збережіть з іменем практична22_3.

Встигли? Перед else: додайте гілку elif s: з відступом lb['text'] = 'Спершу домашнє або лад!'. Для яких відповідей вона виконується?

Перевірте себе

так, ні, так — Можна грати!; ні, так, так — Можна грати!; так, так, ні — Ще не можна (сестра ще працює); ні, ні, так — Ще не можна. Без дужок «так, ні, ні» дає Можна грати!: and виконується раніше за or, і вийшло d or (l and s). Гілка elif s виконується, коли сестра завершила, а ні домашнього, ні ладу немає: ні, ні, так — Спершу домашнє або лад!. Слово так вводьте малими літерами: Так — це вже інший текст, і d буде False.

Перевірте, що в папці Завантаження є практична22_1.py (і практична22_2.py, практична22_3.py, якщо робили). Закрийте вкладку браузера й повідомте вчителя про завершення роботи.
