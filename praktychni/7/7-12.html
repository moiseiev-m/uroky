Завдання 1 · рівень 1 ⭐ «Площі кругів і квадратів» (обов’язкове)

Програма вже вміє рахувати суму площ двох кругів — для цього в ній є функція S(r). Допишіть функцію площі квадрата й порахуйте суму площ двох квадратів.

Показати код заготовки
# Практична робота 3. Площі кругів і квадратів
from math import pi

def S(r):  # площа круга з радіусом r
    return pi * r * r

# тут додайте функцію S2(a) — площа квадрата зі стороною a

r1 = float(input('r1 = '))
r2 = float(input('r2 = '))
print('Сума площ кругів:', round(S(r1) + S(r2), 2))
  1. Відкрийте заготовку й запустіть (F5). Введіть радіуси 1 і 2 — має бути 15.71.
  2. Під коментарем про S2 введіть заголовок функції def S2(a):, а в наступному рядку з відступом — return a * a.
  3. У кінці програми, без відступу, додайте введення сторін: a1 = float(input('a1 = ')) і так само a2.
  4. Останнім рядком виведіть суму: print('Сума площ квадратів:', S2(a1) + S2(a2)).
  5. Запустіть: радіуси 1 і 2, сторони 3 і 4. Збережіть: ⋮ → Файли → Зберегти, ім’я практична3.

Перевірте себе

Радіуси 1 і 2 → Сума площ кругів: 15.71; сторони 3 і 4 → Сума площ квадратів: 25.0.

Завдання 2 · рівень 2 ⭐⭐ «Що вибрали: круги чи квадрати?»

Тепер програма спершу питає, що рахувати: 1 — круги, 2 — квадрати. Для кругів вона ще й порівнює площі: якщо вони різні — каже, на скільки. Частину для квадратів допишіть самі.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практична робота 3. Круги чи квадрати?
from math import pi

def S(r):  # площа круга
    return pi * r * r

def S2(a):  # площа квадрата
    return a * a

v = int(input('1 — круги, 2 — квадрати: '))
if v == 1:
    r1 = float(input('r1 = '))
    r2 = float(input('r2 = '))
    print('Сума площ кругів:', round(S(r1) + S(r2), 2))
    if S(r1) > S(r2):
        print('Площі відрізняються на', round(S(r1) - S(r2), 2))
    elif S(r2) > S(r1):
        print('Площі відрізняються на', round(S(r2) - S(r1), 2))
elif v == 2:
    print('Квадрати — допишіть самі')
  1. Відкрийте заготовку й запустіть. Введіть 1, потім радіуси 1 і 2 — сума 15.71, площі відрізняються на 9.42.
  2. Запустіть ще раз: 1, радіуси 2 і 2. Рядка про різницю немає — площі однакові. Допишіть до цього розгалуження гілку else: (на одному рівні з внутрішнім elif), а під нею з відступом — print('Площі однакові').
  3. Замініть рядок print('Квадрати — допишіть самі') на частину для квадратів: введення a1 і a2, сума площ і порівняння — так само, як для кругів, але з функцією S2.
  4. Перевірте всі випадки: 2, сторони 3 і 4; потім 2, сторони 5 і 5. Збережіть файл з іменем практична3_вибір.

Підказка: скопіюйте рядки гілки для кругів (Ctrl+C, Ctrl+V) і замініть r1, r2 на a1, a2, а S — на S2. Відступи мають лишитися такими самими.

Перевірте себе

1, радіуси 1 і 2 → 15.71 і різниця 9.42; 1, радіуси 2 і 2 → 25.13 і «Площі однакові»; 2, сторони 3 і 4 → 25.0 і різниця 7.0; 2, сторони 5 і 5 → 50.0 і «Площі однакові».

Завдання 3 · рівень 3 ⭐⭐⭐ «Циркові арени» (додаткове)

Для трьох циркових арен відомо радіуси. Знайдіть суму довжин кіл і суму площ арен. Функція krug(r) повертає одразу два результати — довжину кола й площу круга.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Циркові арени: довжини кіл і площі
from math import pi

def krug(r):  # повертає ДВА результати: довжину кола і площу
    c = 2 * pi * r
    s = pi * r * r
    return c, s

r1 = float(input('r1 = '))
c1, s1 = krug(r1)
print('Довжина кола:', round(c1, 2))
print('Площа арени:', round(s1, 2))
  1. Відкрийте заготовку й запустіть з радіусом 1 — має бути 6.28 і 3.14.
  2. Додайте введення r2 і r3 та виклики c2, s2 = krug(r2) і c3, s3 = krug(r3).
  3. Замість виведення для однієї арени виведіть суми: c1 + c2 + c3 і s1 + s2 + s3 (з round).
  4. Додайте процедуру line(), яка виводить лінію print('-' * 20), і викличте її перед результатами й після них. Збережіть файл з іменем арени.

Перевірте себе

Радіуси 1, 2, 3 → сума довжин кіл 37.7, сума площ 43.98; результати між двома лініями з рисок.
