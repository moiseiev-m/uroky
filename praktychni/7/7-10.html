Завдання 1 · рівень 1 ⭐ «Шкільний буфет» (обов’язкове)

Програма рахує, скільки заплатити за булочки. Запустіть її, а потім змініть.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Шкільний буфет: скільки заплатити за булочки
price = 12                                # ціна однієї булочки, грн
count = int(input('Скільки булочок? '))   # кількість — ціле число
total = price * count                     # вартість покупки
print('До сплати:', total, 'грн')
  1. Натисніть ▶ Відкрити заготовку, потім F5. Введіть 3, Enter. Має бути До сплати: 36 грн.
  2. Булочка подорожчала: змініть 12 на 15. Запустіть ще раз з 3 булочками.
  3. Додайте сік: перед рядком з total новий рядок juice = 20, а рядок з total змініть на total = price * count + juice.
  4. Останнім рядком додайте print('Дякуємо за покупку!') і запустіть з 3 булочками.
  5. Збережіть: ⋮ → Файли → Зберегти, ім’я буфет.

Перевірте себе

для 3 булочок програма виводить До сплати: 65 грн, а наступним рядком — подяку.

Завдання 2 · рівень 2 ⭐⭐ «Клумба»

Клумба прямокутна: довжина a м, ширина b м. Її треба обгородити й засадити — по 4 саджанці на кожен квадратний метр. Допишіть формули.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Клумба: довжина огорожі й кількість саджанців (4 саджанці на 1 м²)
a = int(input('Довжина клумби, м: '))
b = int(input('Ширина клумби, м: '))
p = 0     # ← замість 0 — периметр: довжина огорожі
s = 0     # ← замість 0 — площа клумби
k = 0     # ← замість 0 — кількість саджанців
print('Довжина огорожі:', p, 'м')
print('Саджанців:', k)
  1. Відкрийте заготовку. У рядку з p замість 0 введіть периметр прямокутника: 2 * (a + b).
  2. У рядку з s — площу: довжина, помножена на ширину.
  3. У рядку з k — кількість саджанців: площа, помножена на 4.
  4. Запустіть (F5) і перевірте на трьох клумбах з таблиці нижче. Збережіть файл з іменем клумба.

Довжина 2 і ширина 3 → огорожа 10 м, саджанців 24. Довжина 5 і ширина 25 → 60 м і 500. Довжина 1 і ширина 8 → 18 м і 32.

Перевірте себе

усі три клумби дали ті самі числа, що в таблиці вище.

Завдання 3 · рівень 3 ⭐⭐⭐ «Білочки»

Є n білочок і t горішків. Горішки ділять порівну. По скільки цілих горішків отримає кожна білочка і скільки залишиться? Цю програму пишете самі — у заготовці лише введення й підказки.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Білочки: n білочок порівну ділять t горішків
n = int(input('Скільки білочок? '))
t = int(input('Скільки горішків? '))
# k — по скільки цілих горішків отримає кожна білочка (ціла частина частки: //)
# z — скільки горішків залишиться (остача: %)
# виведіть k і z за допомогою print
  1. Відкрийте заготовку й під коментарями допишіть рядок для k, рядок для z і два рядки print.
  2. Перевірте: 3 білочки й 10 горішків, потім 4 білочки й 20 горішків. Збережіть файл з іменем білочки.

Встигли? Ще задача «Кафе»: троє друзів ділять рахунок n грн порівну, чайові — 10 % від рахунку. Скільки платить кожен? Суму вводьте через float, відповідь округліть: round(…, 2). Для 35.27 має вийти 12.93.

Перевірте себе

3 білочки й 10 горішків → кожна отримає 3, залишиться 1; 4 білочки й 20 горішків → по 5, залишиться 0.

Перевірте, що в папці Завантаження є буфет.py (і клумба.py, білочки.py, якщо робили). Закрийте вкладку браузера.

!

Увага! Працюйте з телефоном сидячи, тримайте екран на відстані 30–40 см від очей і кожні 15–20 хвилин робіть перерву: подивіться вдалину.

Працюємо в ЄPython у браузері телефона (Chrome або Safari) — нічого встановлювати не треба. Кнопка ▶ Відкрити заготовку в ЄPython відкриває код завдання.

Запуск — зелена кнопка ▶ унизу праворуч. Коли програма просить число, наберіть його в чорному вікні й натисніть OK. Червоний хрестик × угорі повертає до коду.

Обов’язкове — завдання ⭐. Зробили й перевірили себе — переходьте до ⭐⭐, далі ⭐⭐⭐.

Код пишеться англійськими літерами — перемкніть мову клавіатури. Дужки, лапки, знаки + і = шукайте на клавіатурі символів (кнопка ?123 або 123). Дробові числа — через крапку: 2.5.

Завдання 3 · рівень 3 ⭐⭐⭐ «Білочки: виправте ділення»

Є n білочок і t горішків. Горішки ділять порівну. Програма мала б показати, по скільки цілих горішків отримає кожна білочка і скільки залишиться, але знаки ділення в ній неправильні. Виправте їх.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Білочки: n білочок порівну ділять t горішків
n = int(input('Скільки білочок? '))
t = int(input('Скільки горішків? '))
k = t / n   # по скільки цілих горішків отримає кожна
z = t // n  # скільки горішків залишиться
print('Кожна білочка отримає:', k)
#print('Залишиться горішків:', z)
  1. Відкрийте заготовку й запустіть: 3 білочки й 10 горішків. Кожна білочка «отримує» 3.33… горішка — так не буває. У рядку з k замініть / на // (ціла частина частки).
  2. В останньому рядку видаліть знак # і запустіть знову з тими самими числами. Залишилося 3 горішки? Це неправильно: у рядку з z замініть // на % (остача від ділення).
  3. Перевірте: 3 білочки й 10 горішків, потім 4 білочки й 20 горішків.

Встигли? Ще задача «Кафе»: троє друзів ділять рахунок n грн порівну, чайові — 10 % від рахунку. Скільки платить кожен? Суму вводьте через float, відповідь округліть: round(…, 2). Для 35.27 має вийти 12.93.

Перевірте себе

3 білочки й 10 горішків → кожна отримає 3, залишиться 1; 4 білочки й 20 горішків → по 5, залишиться 0.
