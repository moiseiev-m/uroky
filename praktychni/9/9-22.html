Завдання 1 · рівень 1 ⭐ «Номер телефона» (обов’язкове)

Номер мобільного починається з +, далі 2 цифри — код країни (Україна — 38), 3 цифри — код оператора (Lifecell — 063, 073, 093), решта — номер абонента. Програма з’ясує, чи номер з України, чи це Lifecell і чи парна сума трьох останніх цифр (вправа 3.4.1 на с. 131–132).

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Вправа 3.4.1: номер телефона
a = input('Уведіть телефонний номер: ')
b = a.startswith('+38')
if b: print('Телефон з України')
else: print('Телефон не з України')
  1. Відкрийте заготовку й запустіть (F5). Уведіть номер +380564221423 і натисніть Enter. Запустіть ще раз з номером +410673221525. Чому відповіді різні?
  2. Перевірка оператора: допишіть у кінець c = a[:6], потім if c == '+38063' or c == '+38073' or c == '+38093': print('Lifecell') і else: print('non Lifecell'). Запустіть з номерами +380631276633 і +380651276633.
  3. Сума трьох останніх цифр: цифри — це символи, тож кожну перетворіть на число. Допишіть s = int(a[-1]) + int(a[-2]) + int(a[-3]), потім if s % 2 == 0: print('Сума трьох останніх цифр парна') і else: print('Сума трьох останніх цифр непарна').
  4. Запустіть з номерами +380631276813 і +380651276533.
  5. Збережіть: ⋮ → Файли → Зберегти, ім’я вправа 3.4.1.

Встигли? Номер з України має 13 символів. Допишіть if len(a) != 13: print('Неправильна довжина номера') і перевірте номер +38063127663 — у ньому на одну цифру менше.

Перевірте себе

+380564221423 — «Телефон з України»; +410673221525 — «Телефон не з України». +380631276633 — Lifecell, +380651276633 — non Lifecell. +380631276813: 8 + 1 + 3 = 12 — «парна»; +380651276533: 5 + 3 + 3 = 11 — «непарна». У «Встигли?» номер +38063127663 має 12 символів — «Неправильна довжина номера».

Завдання 3 · рівень 3 ⭐⭐⭐ «Слова в реченні»

У реченні слова розділені одним пропуском або розділовим знаком (кома, крапка, знак оклику) з одним пропуском після нього. Програма рахує слова, як у Задачі 2 (завдання 7 на с. 134). Навчіть її рахувати розділові знаки й шукати слово.

▶ Відкрити заготовку в ЄPython
Показати код заготовки

s = input('Уведіть речення: ')
print('Слів:', s.count(' ') + 1)
  1. Відкрийте заготовку й запустіть. Уведіть Привіт, світе! Ми вчимо Python. Скільки слів?
  2. Допишіть k = s.count(',') + s.count('.') + s.count('!') і print('Розділових знаків:', k).
  3. Допишіть print(s.upper()), print('Python з індексу', s.find('Python')) і print(s.startswith('Привіт')). Запустіть з тим самим реченням.
  4. Запустіть ще раз з тим самим реченням, але після коми поставте два пропуски. Чому слів стало 6? Виправте рядок зі словами: print('Слів:', len(s.split())) — і перевірте знову.
  5. Збережіть файл з іменем завдання 3.4.7.

Встигли? Виведіть усі слова через риску: print('-'.join(s.split())). Чому розділові знаки лишилися біля слів?

Перевірте себе

Привіт, світе! Ми вчимо Python. → слів 5, розділових знаків 3, ПРИВІТ, СВІТЕ! МИ ВЧИМО PYTHON., Python з індексу 24, True. З двома пропусками після коми count дає 6 (пропусків 5), а len(s.split()) — 5; Python тепер з індексу 25. У «Встигли?» — Привіт,-світе!-Ми-вчимо-Python.: split ділить лише за пропусками, а кома й знак оклику — частина слова.
