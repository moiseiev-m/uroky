Завдання 1 · рівень 1 ⭐ «Найдовше слово» (обов’язкове)

Дано рядок, у якому слова відокремлені одне від іншого одним пропуском. Створіть проєкт для визначення найбільшої довжини слова в цьому рядку.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практична 5-1: найдовше слово
s = input('Уведіть рядок (слова через один пропуск): ')
words = s.split(' ')
max_len = 0
# цикл: перегляньте всі слова word зі списку words
# якщо довжина слова більша за max_len — запам’ятайте її в max_len

print('Найбільша довжина слова в рядку:', max_len)
  1. Відкрийте заготовку. Рядок 3 уже розбиває введений рядок на список слів words, а max_len спершу дорівнює 0.
  2. Під коментарями допишіть цикл for word in words:, а в ньому — розгалуження: якщо len(word) > max_len, то max_len = len(word). Стежте за відступами.
  3. Запустіть (F5) і введіть Оля має кота. Потім запустіть ще раз з рядком Ми пишемо програму на Python.
  4. Збережіть: ⋮ → Файли → Зберегти, ім’я Практична 5-1.

Встигли? Виведіть ще й саме найдовше слово: перед циклом додайте longest = '', а поруч із max_len = len(word) — longest = word з тим самим відступом.

Перевірте себе

Оля має кота → 4; Ми пишемо програму на Python → 8. Найдовші слова — кота і програму. Якщо вийшло 3 — ви написали len(words) (кількість слів) замість len(word).

Завдання 2 · рівень 2 ⭐⭐ «Пропуски поспіль» (обов’язкове)

Дано рядок, у якому слова відокремлені одне від іншого пропусками. Створіть проєкт для визначення найбільшої кількості пропусків, що розташовані поспіль.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Практична 5-2: найбільше пропусків поспіль
s = input('Уведіть рядок з довільною кількістю пропусків: ')
max_spaces = 0       # найбільше пропусків поспіль
current_spaces = 0   # пропусків поспіль зараз
# цикл: перегляньте всі символи char рядка s
# пропуск — current_spaces += 1; якщо стало більше за max_spaces — запам’ятайте
# не пропуск (else) — current_spaces = 0

print('Найбільша кількість пропусків поспіль:', max_spaces)
  1. Відкрийте заготовку: рядок уже вводиться, обидва лічильники дорівнюють 0. Під коментарями допишіть цикл for char in s:, а в ньому — if char == ' ': (між лапками один пропуск).
  2. У гілці if напишіть current_spaces += 1, а нижче — ще одне розгалуження: якщо current_spaces > max_spaces, то max_spaces = current_spaces.
  3. Допишіть гілку else: — у ній current_spaces = 0: літера перериває серію пропусків.
  4. Запустіть і введіть слово кіт, 2 пропуски, і, 3 пропуски, пес. Потім — рядок без пропусків, наприклад кіт. Збережіть файл з іменем Практична 5-2.

Встигли? Розв’яжіть задачу ще одним способом — без лічильника: k = 0, далі цикл while ' ' * (k + 1) in s:, у ньому k += 1. Виведіть k — відповідь має збігтися з max_spaces.

Перевірте себе

кіт, 2 пропуски, і, 3 пропуски, пес → 3; кіт → 0. Якщо вийшло 5 — ви забули гілку else і програма рахує всі пропуски.

Завдання 3 · рівень 3 ⭐⭐⭐ «Слова по одному» (додаткове)

Завдання 2 · рівень 2 ⭐⭐ «Пропуски поспіль: знайдіть 3 помилки» (обов’язкове)

Програма мала б знайти найбільшу кількість пропусків, що стоять поспіль. У рядку з програми між словами «кіт» і «і» — 2 пропуски, а між «і» і «пес» — 3, тож правильна відповідь — 3. Але в програмі три помилки. Знайдіть і виправте їх.

▶ Відкрити заготовку в ЄPython
Показати код заготовки
# Пропуски поспіль. У програмі 3 помилки
s = 'кіт  і   пес'
max_spaces = 0
current_spaces = 0
for char in s:
    if char = ' ':
        current_spaces += 1
        if current_spaces < max_spaces:
            max_spaces = current_spaces
    else:
        current_spaces = 1
print('Найбільше пропусків поспіль:', max_spaces)
  1. Відкрийте заготовку й запустіть. ЄPython покаже помилку в рядку 6: щоб порівняти, потрібні два знаки рівності — ==.
  2. Виправте й запустіть знову. Програма пише 0, хоча пропуски є. Найбільше значення треба оновлювати, коли лічильник більший за нього. Знайдіть і виправте знак порівняння.
  3. Тепер програма пише 4, а має бути 3. Після літери лічильник має починати з нуля. Знайдіть і виправте число в гілці else.

Перевірте себе

Після трьох виправлень — «Найбільше пропусків поспіль: 3».
