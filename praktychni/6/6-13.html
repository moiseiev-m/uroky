Практичне завдання

Векторні фігури в Photopea

Тема: Графіка й мультимедіа

Немає комп’ютера — виберіть «З телефона»: завдання на ту саму тему, їх можна виконати на телефоні.

!

Увага! Під час роботи з комп’ютером дотримуйтеся вимог безпеки життєдіяльності та санітарно-гігієнічних норм.

Малюємо в онлайн-редакторі Photopea: відкрийте в браузері сайт photopea.com і натисніть Start using Photopea. Меню відкриється українською.

У Photopea кожна фігура стає окремим векторним шаром — Форма 1, Форма 2… на панелі Шари. Щоб змінити фігуру, клацніть її шар на панелі Шари.

Праворуч може бути реклама — не клацайте її. Файли Photopea зберігає в папку Завантаження: після роботи перенесіть їх у свою папку Прізвище_6-13.

Помилилися — Ctrl+Z. Інструменти фігур сховані під однією кнопкою: клацніть її правою кнопкою миші й виберіть Прямокутник, Еліпс, Лінія або Параметрична форма. Тримайте Shift, щоб еліпс став кругом.

Завдання 1

Намалюйте надкушене яблуко з фігур, як на картинці-зразку нижче.

  1. Натисніть Новий проєкт. Назва — Прізвище_6-13_1, Ширина — 800, Висота — 800 пікселів, Тло — Білий. Створити.
  2. Яблуко: клацніть правою кнопкою інструмент фігур і виберіть Еліпс. До малювання у верхньому рядку: Заповнити — червоний, Обведення — темно-червоний, товщина 6 px. Намалюйте великий круг.
  3. Тінь: унизу панелі інструментів клацніть верхній квадратик кольорів і виберіть темно-червоний. Еліпсом намалюйте вузький овал на правому боці яблука. Клацніть Заповнити → Тип заповнення — третя кнопка (градієнт). Відкрийте список градієнтів (трикутничок) і виберіть другий — з кольору в прозорий. Тип — Лінійний, Кут — 180. Обведення — без кольору (перекреслений квадратик).
  4. Плодоніжка — інструмент Лінія, Обведення коричневе, 12 px. Листок — зелений Еліпс; поверніть його: Редагувати → Вільна трансформація, потягніть мишею трохи збоку від кута рамки, Enter.
  5. Надкус: Еліпс, Заповнити — білий, Обведення — без кольору. Намалюйте три круги, що накривають правий край яблука.
  6. Змініть уже намальоване: на панелі Шари клацніть шар яблука (Форма 1), виберіть інструмент Еліпс і у верхньому рядку поставте Обведення — без кольору. Темно-червоний контур зникне, а саме яблуко лишиться.

Збережіть двічі: Файл → Зберегти як PSD — файл з усіма шарами; потім Файл → Експортувати як → PNG, Зберегти.

Перевірте себе

праворуч на яблуці — тінь, що плавно зникає; у яблука немає темного контуру; на панелі Шари — по шару на кожну фігуру.

Завдання 2

Намалюйте будиночок, а потім змініть його, не перемальовуючи: перефарбуйте, зробіть тонший контур, скопіюйте вікно.

  1. Файл → Створити. Назва — Прізвище_6-13_2, 1000 × 800 пікселів, Тло — світло-блакитне (квадратик кольору праворуч від списку Тло). Створити.
  2. Стіна — Прямокутник: Заповнити — жовтий, Обведення — коричневе, 8 px. Дах — Параметрична форма: у списку праворуч у верхньому рядку — Багатокутник, Сторони — 3; Заповнити — червоний. Намалюйте трикутник над стіною.
  3. Вікно — Прямокутник блакитного кольору. Скопіюйте його: Шар → Дублювати шар, OK. Інструментом Виділення контуру (стрілка з квадратиком на панелі інструментів) пересуньте копію праворуч.
  4. Дерево ліворуч від будинку: стовбур — коричневий Прямокутник, крона — зелений Еліпс.
  5. Змініть уже намальоване: на панелі Шари клацніть шар стіни, виберіть Прямокутник і поставте Заповнити — світло-рожевий, Обведення — 3 px. Потім клацніть шар даху й змініть його колір на коричневий.

Збережіть: Файл → Зберегти як PSD, потім Файл → Експортувати як → PNG, Зберегти.

Ваш будиночок може відрізнятися від зразка кольорами й розмірами.

Перевірте себе

стіна рожева з тонким контуром, дах коричневий, два однакові вікна; на панелі Шари — окремі шари стіни, даху, двох вікон і дерева.

Завдання 3 (додаткове)

Намалюйте захід сонця над морем: небо й сонце — з градієнтною заливкою.

  1. Новий проєкт Прізвище_6-13_3, 1200 × 800 пікселів.
  2. Небо: Прямокутник на все полотно. Заповнити → градієнт, у списку градієнтів виберіть різнокольоровий (наприклад, помаранчево-жовтий або веселковий). Тип — Лінійний, Кут — 90: кольори підуть знизу вгору. Спробуйте Кут — 0 і 45, подивіться, як змінюється напрям, і поверніть 90.
  3. Сонце: Еліпс із Shift — круг. Заповнити → градієнт з жовтого в помаранчевий, тип — Радіальний: колір розходиться від центру колами. Обведення — без кольору.
  4. Море: синій Прямокутник на нижню третину полотна — він закриє низ сонця, бо його шар вище.
  5. Хвилі: Лінія білого кольору, 4 px. Намалюйте одну хвилю, скопіюйте її (Ctrl+C, Ctrl+V) кілька разів і пересуньте копії інструментом Виділення контуру. Зайву копію видаліть: шар на панелі Шари → кнопка кошика внизу панелі.

Збережіть: Файл → Експортувати як → PNG, Зберегти.

Ваш захід сонця може відрізнятися від зразка кольорами градієнтів.

Перевірте себе

небо змінює колір знизу вгору, сонце світліше в центрі, море закриває низ сонця; кожна хвиля — окремий шар.

Перенесіть із Завантажень у свою папку і надішліть учителю файли Прізвище_6-13_1.png, Прізвище_6-13_2.png і, якщо робили додаткове, Прізвище_6-13_3.png.

!

Увага! Працюйте з телефоном сидячи, тримайте екран на відстані 30–40 см від очей і кожні 15–20 хвилин робіть перерву: подивіться вдалину.

Малюємо в Photopea у браузері телефона (Chrome або Safari): відкрийте photopea.com і натисніть Start using Photopea — меню відкриється українською.

Кожна фігура стає окремим векторним шаром — Форма 1, Форма 2… Панель Шари — значок зі стосом аркушів праворуч: щоб змінити фігуру, торкніться її шару.

Інструменти фігур сховані під однією кнопкою: утримуйте на ній палець і виберіть Прямокутник, Еліпс, Лінія або Параметрична форма.

Помилилися — Редагувати → Крок назад. Не видно налаштування у верхньому рядку (товщина, тип градієнта) — поверніть телефон горизонтально. Реклами внизу не торкайтеся.

Завдання 1

Намалюйте надкушене яблуко з фігур, як на картинці-зразку нижче.

  1. Новий проєкт: Назва — Прізвище_6-13_1, 800 × 800 пікселів, Тло — Білий → Створити.
  2. Яблуко: Еліпс, у верхньому рядку Заповнити — червоний, Обведення — темно-червоний. Проведіть пальцем великий круг.
  3. Тінь: вузький овал на правому боці яблука. Заповнити → Тип заповнення — третя кнопка (градієнт), у списку градієнтів — другий (з кольору в прозорий), Кут — 180. Обведення — без кольору.
  4. Плодоніжка — Лінія коричнева; листок — зелений Еліпс, поверніть його: Редагувати → Вільна трансформація, потягніть збоку від кутка рамки, ✓.
  5. Надкус: три білі круги без обведення на правому краї яблука. Потім торкніться шару яблука (Форма 1) на панелі Шари, виберіть Еліпс і поставте Обведення — без кольору: контур зникне.

Збережіть: Файл → Експортувати як → PNG → Зберегти.

Перевірте себе

праворуч на яблуці — тінь, що плавно зникає; у яблука немає темного контуру; на панелі Шари — по шару на кожну фігуру.

Завдання 2

Намалюйте будиночок, а потім змініть його, не перемальовуючи: перефарбуйте й скопіюйте вікно.

  1. Файл → Створити: Прізвище_6-13_2, 1000 × 800 пікселів, Тло — світло-блакитне → Створити.
  2. Стіна — Прямокутник жовтий із коричневим Обведенням. Дах — Параметрична форма: у верхньому рядку (поверніть телефон горизонтально) — Багатокутник, Сторони — 3, Заповнити — червоний.
  3. Вікно — блакитний Прямокутник. Скопіюйте: Шар → Дублювати шар → OK. Інструментом Виділення контуру (стрілка з квадратиком) пересуньте копію праворуч.
  4. Змініть уже намальоване: торкніться шару стіни на панелі Шари, виберіть Прямокутник і поставте Заповнити — світло-рожевий. Потім шар даху — коричневий колір.

Збережіть: Файл → Експортувати як → PNG → Зберегти. Ваш будиночок може бути без дерева й іншими кольорами.

Перевірте себе

стіна рожева, дах коричневий, два однакові вікна; на панелі Шари — окремі шари стіни, даху й двох вікон.

Завдання 3 (додаткове)

Намалюйте захід сонця над морем: небо й сонце — з градієнтною заливкою.

  1. Новий проєкт Прізвище_6-13_3, 1200 × 800 пікселів.
  2. Небо: Прямокутник на все полотно, Заповнити → градієнт різнокольоровий, тип — Лінійний, Кут — 90.
  3. Сонце: Еліпс, Заповнити → градієнт з жовтого в помаранчевий, тип — Радіальний, Обведення — без кольору.
  4. Море: синій Прямокутник на нижню третину — він закриє низ сонця, бо його шар вище.
  5. Хвиля: біла Лінія. Скопіюйте її (Редагувати → Копіювати, Редагувати → Вставити) кілька разів і пересуньте копії інструментом Виділення контуру.

Збережіть: Файл → Експортувати як → PNG → Зберегти.

Перевірте себе

небо змінює колір знизу вгору, сонце світліше в центрі, море закриває низ сонця; кожна хвиля — окремий шар.
